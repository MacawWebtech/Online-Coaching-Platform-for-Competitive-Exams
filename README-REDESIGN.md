# Examora / Academy redesign

This is a static HTML/CSS/JavaScript project with 37 pages. Open `index.html` or run `python -m http.server 8000` from this folder.

- `index.html`: Classic coaching academy landing page
- `home-2.html`: Premium personalised preparation landing page
- `assets/css/academy.css`: New two-color design system and responsive layout
- `assets/js/academy.js`: accessible interactions and theme/RTL support
- `vercel.json`: optional static hosting configuration; this ZIP has **not** been deployed.

## Before publishing
Replace illustrative success data, portraits and claims with consented, verified student outcomes. Login and registration forms are frontend UI and need a real backend; Google/Apple require OAuth credentials. Mock-test and dashboard sample data are not real user records.
