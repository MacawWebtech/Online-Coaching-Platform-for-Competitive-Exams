HEADING BACKGROUND IMAGES — ALL 18 FILES ARE INCLUDED

Replace any JPG in this folder with your own photo, keeping its exact filename.
For example: about.jpg changes About; courses.jpg changes Courses.
Recommended: landscape JPG, 1920 x 900 or larger. Cover cropping adapts to the screen.
There is no full-banner colour overlay in either light or dark mode.

To use a different filename or PNG/WebP:
Open the corresponding HTML page and change BOTH image paths in its heading section
(the --page-heading-image value and the heading-image-layer background-image value).
HTML paths start with assets/images/heading-backgrounds/ and are relative to the HTML page.
Do not use a Windows drive path. Keep filename spelling and uppercase/lowercase exact.
