02 / HOW THE PROGRAMME WORKS

Make each study session count.

Move from learning to practice with a repeatable weekly routine. The schedule is an example, not a promise of a particular result.

  1. UnderstandWork through one focused concept and its worked examples.
  2. ApplyAttempt a short set of topic-based questions.
  3. ReviewNote the mistakes and revisit difficult ideas.
  4. RepeatReturn to a similar set before moving on.
